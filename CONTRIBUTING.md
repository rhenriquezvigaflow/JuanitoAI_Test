# Convenciones de trabajo

- Escribir los mensajes de commit en español.
- Mantener README y arquitectura alineados con las decisiones vigentes.
- No subir expedientes reales, precios, documentos de proveedores, credenciales ni resultados privados.
- Utilizar muestras sintéticas para pruebas del repositorio.
- Distinguir revisión documental, pruebas aisladas y validación integral al informar resultados.
